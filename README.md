# 公交腕上导航（Amap Band Bridge）

把高德地图公交语音导航中的当前站、下一站和剩余站数，转换成小米运动健康能够转发到手环的标准通知。

## 当前适配目标

- 小米 14 / Android 16 / HyperOS 3
- 高德地图 17.00.0.1292（`com.autonavi.minimap`）
- 小米运动健康 3.59.1（`com.mi.health`）
- LSPosed 2.0.2

## 使用

1. 安装 APK，在 LSPosed 中启用“公交腕上导航”，作用域只勾选“高德地图”。
2. 强制停止并重新打开高德地图。
3. 打开“公交腕上导航”，允许通知，点击“发送手环测试通知”。
4. 完全退出并重新打开小米运动健康，在设备通知设置的“自定义消息通知”中允许“公交腕上导航”通知同步。
5. 开启高德公交语音导航。应用页面的“最近捕获”可用于确认适配状态。

模块仅在高德进程内观察含公交/站点关键词的界面文本、无障碍描述、TTS 文本和导航通知文本；不会联网或上传数据。

## 原理与限制

高德 17.00 的公交后台通知只有固定文案，站点状态实际由 AJX 页面维护。本模块在高德进程内捕获 AJX 最终写入 Android View 的文本和语音播报，并通过显式本地广播交给独立应用生成标准通知。路线方案列表只写入诊断记录，不会触发手环通知。

0.1.4 起会直接观察高德自定义 AJX `Label`（它不是 Android `TextView`），并兼容高德 17.00 实际产生的“11站后后 … 出站”和“1站后后 … 换乘”等文案。相同剩余站数不会重复提醒；同一时刻存在多段行程时优先显示最近需要执行的动作。
